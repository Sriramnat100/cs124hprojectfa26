# 3D scooter model

The home page loads `scooter.glb` from this folder. The file is **not in git** (see `.gitignore`)
until we confirm its license, so a fresh clone shows a simple placeholder scooter built in code.

To see the real model, put a `.glb` file here named `scooter.glb` and refresh the page.
If it faces the wrong way, change `MODEL_TURN` in `src/landing/scene.js`.
